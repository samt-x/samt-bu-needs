# samt-bu-needs – Behov

Behovene i SAMT-BU (Sammenhengende tjenester for barn og unge): de nummererte casene (use cases) og andre behov.

- **Sider:** [Behov](https://docs.samt-bu.no/behov/) på docs.samt-bu.no.
  Repoet er en Hugo-modul, og `content/` monteres på `behov`. Adressene er de samme som før flyttingen.
- **Tilgang:** alle i SAMT-BU (`samt-bu-alle`) kan skrive her, direkte fra «Endre» på nettstedet.
- **Historikk:** sidene lå i `samt-bu-docs` under `content/behov/` til 2026-11-15, og historikken derfra er tatt med.
  Sidekommentarer til casene ligger som issues her.

Bakgrunn: [solution-samt-bu-docs#82](https://github.com/samt-x/solution-samt-bu-docs/issues/82) (repo per ansvarsområde).
